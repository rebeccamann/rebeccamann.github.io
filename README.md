# rebeccamann.github.io

Contains session files for Mol* interactive viewer, for E. Coli membrane protein complexes. The session files contain the protein complex with and without its signal peptide (if applicable), as well as the protein within a membrane.

To view the files, use the following link with 'cpx-XXXX.molx' replaced by the relevant file name:

https://molstar.org/viewer/?snapshot-url=https://raw.githubusercontent.com/rebeccamann/rebeccamann.github.io/main/cpx-XXXX.molx&snapshot-url-type=molx
