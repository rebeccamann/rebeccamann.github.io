# rebeccamann.github.io

A list of .molx files (Mol* session files) for membrane protein complexes in E. Coli, strain K12. These files can then be opened in the browser using Mol*, with a link of the form:

https://molstar.org/viewer/?snapshot-url=https://raw.githubusercontent.com/rebeccamann/rebeccamann.github.io/main/cpx-0000.molx&snapshot-url-type=molx

Where cpx-0000 is replaced with the relevant file.
Inside is a cartoon representation of the complex, coloured according to AlphaFold's plDDT confidence score. There is also an option to view the complex situated in a membrane.
